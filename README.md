# Laravel Feature Heatmap — GitHub Pages site

Static landing page and documentation for `farukcoder/laravel-feature-heatmap`.

## Files
- `index.html` — product landing page
- `docs.html` — documentation
- `styles.css` — responsive light/dark theme
- `script.js` — theme toggle, screenshot tabs, copy buttons, docs search
- `images/` — dashboard screenshots

## Publish on GitHub Pages
1. Copy these files into the `gh-pages` branch root of `Farukcoder/laravel-feature-usage`.
2. Commit and push the branch.
3. In repository **Settings → Pages**, select **Deploy from a branch**, branch `gh-pages`, folder `/ (root)`.

The site uses only static HTML, CSS, JavaScript, and the supplied screenshots.
